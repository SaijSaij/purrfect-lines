# Environment files

- Never read, print, copy or search the contents of .env files (.env, .env.*),
  by any means: file tools, shell commands, scripts or other tools. This also
  applies when debugging.
- To learn which variables exist, read .env.example or ask me.
- If a rule blocks you from reading a file, do not look for a workaround.
  Tell me what you need.
- Never write real secret values into .env.example, code, tests, docs or
  commit messages.
